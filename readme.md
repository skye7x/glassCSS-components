# Glass CSS Components ✨

A collection of 40+ Glass CSS components that you can use freely in your own projects.

I made these components to help you quickly add modern glassmorphism effects to websites without having to build everything from scratch.

## Features

- glass CSS components
- modern glassmorphism design
- easy to copy and customize
- responsive-friendly
- pure HTML & CSS

## Components

The collection includes a variety of glass-style UI components, such as:

- Cards
- Buttons
- Navigation bars
- Forms
- Inputs
- Modals
- Badges
- Pricing cards
- Profile cards
- Toggles
- Tooltips
- Alerts
- And many more..!
